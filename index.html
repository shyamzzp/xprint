xprint

Print to a cheap 58mm Xprinter ESC/POS thermal printer from the terminal. macOS & Linux.

Install

curl -fsSL https://shyamzzp.github.io/xprint/install.sh | bash

Installs prerequisites, validates, then sets up the xprint command. Idempotent, safe to re-run to update.

Use

echo "hello world" | xprint     # print text
xprint -t                       # teletype: prints each line as you type
xprint --help                   # every command and flag
